# FusionPDF - 在 IntelliJ IDEA 中隐秘摸鱼的 PDF 阅读器

## 介绍
**FusionPDF** 是一款专为 IntelliJ IDEA 及其他 JetBrains IDE 设计的 PDF 阅读插件。不同于传统 PDF 阅读器，FusionPDF 会自动融合 PDF 背景与 IDEA 主题，让阅读更加轻松，毫无违和感。

无论是查阅技术文档、阅读论文，还是在写代码时偷偷摸鱼看 PDF，FusionPDF 都能完美隐藏，让你在 IDE 里畅享阅读而不被发现。

## 功能特色
- 📂 **拖拽打开**：直接拖动 PDF 文件到 IntelliJ IDEA，即可自动打开。
- 🎨 **主题融合**：自动适配 IDE 主题，阅读体验丝滑无痕。
- 🚀 **极简无干扰**：无多余 UI 元素，专注阅读不分心。
- 🕵️ **隐蔽摸鱼模式**：深度整合 IDE，阅读 PDF 不会被察觉，摸鱼无压力！
- 🔥 **深色模式优化**：智能调整文字颜色，对比清晰不伤眼。

## 安装方式
1. 打开 **IntelliJ IDEA**（或其他 JetBrains IDE）。
2. 进入 **设置** → **插件**。
3. 搜索 **FusionPDF** 并点击 **安装**。
4. 重启 IDE，开始隐秘阅读之旅！

## 使用方法
1. 拖动 PDF 文件到 IntelliJ IDEA。
2. PDF 将在底部的 **FusionPDF** 工具窗口打开。
3. 享受无缝融合的隐蔽摸鱼体验！

# FusionPDF - Seamless PDF Integration for IntelliJ IDEA

## Introduction
**FusionPDF** is a powerful and stealthy PDF reader plugin for IntelliJ IDEA and other JetBrains IDEs. Unlike traditional PDF viewers, FusionPDF seamlessly blends the PDF background with your IDE theme, making it easier to read while keeping a distraction-free environment.

Whether you are reading documentation, research papers, or secretly skimming through non-work-related PDFs, FusionPDF ensures a smooth experience without standing out in your workspace.

## Features
- 📂 **Drag & Drop Support**: Open PDFs directly by dragging them into IntelliJ IDEA.
- 🎨 **Theme Integration**: PDF background automatically adjusts to match your IDE theme for a natural feel.
- 🚀 **Distraction-Free Reading**: No clunky UI elements—just pure, seamless reading.
- 🕵️ **Stealth Mode**: Perfectly integrated into the IDE, making it easy to read PDFs while coding without raising suspicion.
- 🔥 **Optimized for Dark Mode**: Enhance readability with adaptive contrast for text.

## Installation
1. Open **IntelliJ IDEA** (or any JetBrains IDE).
2. Go to **Preferences** → **Plugins**.
3. Search for **FusionPDF** and click **Install**.
4. Restart your IDE and start reading!

## How to Use
1. Drag and drop a PDF file into IntelliJ IDEA.
2. The file will open in the **FusionPDF** Tool Window on the left.
3. Enjoy a distraction-free, theme-integrated reading experience.
